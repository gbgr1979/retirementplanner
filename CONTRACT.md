# Internal contract
Static vanilla ES modules; Node built-in tests; no runtime dependencies.
Plan version 1:
{version:1,name,startMonth:'2026-11',endAge:95,includePartner:false,inflation:2.5,scenarioSpread:2,monthlySpending:2500,spendingStart:'2044-11',people:[{id:'you'|'partner',name,dob:'YYYY-MM-DD',retirementMonth:'YYYY-MM',region:'rUK'|'scotland',taxFreeUsed:0}],pots:[{id,name,owner,type:'savings'|'cashIsa'|'stocksIsa'|'sipp'|'workplace',balance,monthlyContribution,employerContribution,contributionBasis:'gross'|'netRelief',growth,fee,contributionStart,contributionEnd,accessAge:57}],incomes:[{id,name,owner,type:'state'|'db'|'other',monthlyAmount,startMonth,endMonth,escalation}],events:[{id,name,month,type:'withdrawal'|'transfer',potId,toPotId:'',amount}]}
Rates in percent per annum. Contributions at month start then growth then charges then events. Monthly contributions are amount entering pot when gross, or net personal /0.8 when netRelief. Employer always gross. Monthly spending in startMonth pounds, inflation indexed; no automatic withdrawals: shortfall means net income plus event withdrawals less spending, no invented funding. Annual pension tax estimate allocated across that tax year's income; current 2026/27 rules frozen. Contributions funded externally and not deducted from retirement spending unless clearly reported. Income monthly amount expressed at plan start pounds; escalation annual effective. Events fixed nominal gross removal; transfer only accessible same-owner nonpension pots (no pension transfer or subscription allowance inference).
API src/model.js: export project(plan,{scenario:'base'|'lower'|'higher'}={}), returns {months:[{month,balances:{id:value},accessible,locked,total,incomeGross,incomeNet,withdrawalsGross,withdrawalsNet,tax,spending,shortfall,contributions,growth,fees,warnings:[]}],years:[{year,opening,contributions,growth,fees,withdrawals,closing,incomeGross,incomeNet,spending,shortfall,tax,accessible,locked,balances}],warnings:[],assumptions:[]}. Years are calendar years for charts; tax engine uses Apr-Mar. Transfers not counted as household withdrawals. project never mutates plan. End at primary person endAge bounded max 80 years.
API src/plan.js: export createExamplePlan(), validatePlan(plan) returns {valid,errors}, parsePlan(text) returns validated plan or throws Error; serializePlan(plan) validates and returns JSON text. Strict unknown/prototype keys rejection and limits; names plain text. UI uses textContent/escaped strings not untrusted HTML. Dates valid Gregorian and months regex+range; all references checked. 1MB import max.
